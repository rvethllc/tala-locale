# Code of Conduct

## The short version

Be respectful. No harassment, discrimination, or personal attacks.

## The longer version

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

In short:
- Be welcoming and inclusive
- Assume good intent
- Disagree on ideas, never on people
- If someone is being harassed, report it

## Reporting

Report issues to [engineering@rveth.in](mailto:engineering@rveth.in). All reports are confidential.
